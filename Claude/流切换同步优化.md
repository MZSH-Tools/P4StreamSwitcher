# 流切换同步优化

## 问题

- [x] `clean` 命令会删除缓存文件（Saved/, Intermediate/, DerivedDataCache/），导致每次切换后需重新编译着色器
- [x] `clean` 需要扫描所有文件，10万+文件时很慢

## 方案

使用 `.p4ignore` 自动判断哪些文件需要保留，实现智能清理。

### 文件分类逻辑

```
对于本地每个文件：
├── 在 have list 中？ → 保留（depot 管理）
├── 匹配 .p4ignore？ → 保留（缓存/忽略文件）
└── 否则 → 删除（多余文件）
```

### 同步流程

- [x] p4 opened 检查未提交修改 → 有则拒绝切换
- [x] 切换 Stream 和 Root
- [x] sync -k 更新 have list
- [x] 读取并解析 .p4ignore 规则
- [x] p4 have 获取 have list（depot 文件 → 本地路径）
- [x] 遍历工作区 → 删除（不在 have list 且不匹配 .p4ignore）的文件
- [x] diff -se → sync -f --parallel 覆盖内容不同的文件
- [x] diff -sd → sync -f --parallel 下载缺失的文件

## 离线目录支持

### 需求

- [x] 标记某些流对应的工作区为"离线目录"
- [x] 离线目录切换时使用 `reconcile` 保留本地修改
- [x] 一键打开 P4V 并切换到当前客户端

### 缓存结构变更

```json
// 旧格式
{ "//depot/project/branch": "D:/workspace" }

// 新格式（自动迁移）
{ "//depot/project/branch": { "workspace": "D:/workspace", "offline": false } }
```

### 切换流程对比

| 步骤 | 普通目录 | 离线目录 |
|------|---------|---------|
| 1 | sync -k | sync -k |
| 2 | 删除多余文件 | - |
| 3 | diff -se/-sd | - |
| 4 | sync -f | reconcile |
| 结果 | 本地与 depot 一致 | 差异放入默认 changelist |
