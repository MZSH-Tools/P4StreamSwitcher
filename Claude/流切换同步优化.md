# 流切换同步优化

## 问题

- [ ] `clean` 命令会删除缓存文件（Saved/, Intermediate/, DerivedDataCache/），导致每次切换后需重新编译着色器
- [ ] `clean` 需要扫描所有文件，10万+文件时很慢

## 方案

使用 `.p4ignore` 自动判断哪些文件需要保留，实现智能清理。

### 文件分类逻辑

```
对于本地每个文件：
├── 在 have list 中？ → 保留（depot 管理）
├── 匹配 .p4ignore？ → 保留（缓存/忽略文件）
└── 否则 → 删除（多余文件）
```

### 同步流程

- [ ] p4 opened 检查未提交修改 → 有则拒绝切换
- [ ] 切换 Stream 和 Root
- [ ] sync -k 更新 have list
- [ ] 读取并解析 .p4ignore 规则
- [ ] p4 have 获取 have list（depot 文件 → 本地路径）
- [ ] 遍历工作区 → 删除（不在 have list 且不匹配 .p4ignore）的文件
- [ ] diff -se → sync -f --parallel 覆盖内容不同的文件
- [ ] diff -sd → sync -f --parallel 下载缺失的文件
