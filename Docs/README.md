# P4StreamSwitcher 使用教程

## 功能介绍

P4StreamSwitcher 是一个基于 tkinter 的 GUI 工具，用于简化 Perforce 流工作区的切换操作。

### 主要功能

| 功能 | 说明 |
|------|------|
| 流客户端选择 | 自动列出本机当前用户的所有流客户端 |
| 项目选择 | 显示所有 mainline 类型的流项目 |
| 分支选择 | 显示选中项目下的所有流分支 |
| 工作区目录 | 可自定义切换后的本地工作目录，支持浏览按钮选择 |
| 目录缓存 | 自动记住每个流对应的工作区目录，显示路径来源 |
| 未提交检查 | 切换前检查是否有未提交修改，有则拒绝切换 |
| P4V 检测 | 切换前检查 P4V 是否运行中，避免冲突 |
| 智能同步 | 基于 `.p4ignore` 保护缓存文件，精准同步差异文件 |

## 环境配置

### 前置条件

1. 安装 Python 3.x
2. 安装依赖：
   ```bash
   pip install p4python platformdirs
   ```
3. 确保已配置 Perforce 环境变量：
   ```bash
   p4 set P4PORT=your.server:1666
   p4 set P4USER=your_username
   ```

### 验证环境

```bash
p4 info
```

如能正常显示服务器信息，说明环境配置正确。

## 使用说明

### 启动工具

```bash
python Main.py
```

### 界面说明

启动后会显示以下信息：

- **服务器**：当前连接的 P4 服务器地址（只读）
- **用户**：当前 P4 用户名（只读）
- **流客户端**：选择要操作的客户端
- **选择流项目**：目标项目
- **选择流分支**：目标分支
- **工作区目录**：点击打开目录选择对话框，灰色表示使用默认路径（未缓存，切换时需确认）

### 操作步骤

1. **选择流客户端**：点击下拉框，选择需要切换的客户端
2. **选择目标项目**：点击下拉框，选择目标流项目
3. **选择目标分支**：点击下拉框，选择目标流分支
4. **确认工作区目录**：点击可打开目录选择对话框修改路径
5. **点击"一键切换"**：开始执行切换操作

### 同步流程

点击"一键切换"后，工具会自动执行以下步骤：

1. **确认默认路径**：如使用默认路径（灰色），弹窗询问是否使用该路径
2. **检查未提交修改**：如有未提交文件，拒绝切换并提示用户
3. **检查 P4V 状态**：如 P4V 正在运行，拒绝切换并提示用户关闭
4. **检查目录**：如目录不存在，询问是否创建
5. **切换流配置**：更新客户端的 Stream 和 Root 设置
6. **保存目录缓存**：记住当前流对应的工作区目录
7. **更新 have list**：执行 `sync -k` 更新文件索引
8. **解析 .p4ignore**：读取忽略规则，保护缓存文件
9. **清理多余文件**：删除不在 have list 且不匹配 .p4ignore 的文件
10. **检测差异文件**：使用 `diff -se` 检测内容不同的文件
11. **检测缺失文件**：使用 `diff -sd` 检测本地缺失的文件
12. **同步文件**：使用 `sync -f --parallel` 下载差异和缺失文件

### 进度与日志

- 操作开始后会显示进度条
- 日志区域实时显示操作详情
- 操作完成后进度条自动隐藏

## 工作区目录缓存

工具会自动记住每个流对应的工作区目录：

- 缓存按客户端分组存储
- 切换流时自动加载对应的缓存目录
- 缓存存储在系统缓存目录中（Windows: `%LOCALAPPDATA%`，Mac: `~/Library/Caches`）

## 智能同步说明

### 缓存保护

工具会自动保护以下目录（即使没有 `.p4ignore` 文件）：

- `Saved/` - UE 项目保存数据
- `Intermediate/` - UE 中间文件
- `DerivedDataCache/` - UE 派生数据缓存
- `Binaries/` - 编译输出
- `.vs/` - Visual Studio 配置
- `.idea/` - JetBrains IDE 配置
- `.git/` - Git 仓库
- `*.log` - 日志文件

### 自定义忽略规则

在工作区根目录创建 `.p4ignore` 文件，添加自定义规则：

```
# 忽略目录（以 / 结尾）
MyCache/
Build/

# 忽略特定扩展名
*.tmp
*.bak

# 忽略特定路径
Config/Local/*

# 取消忽略（! 前缀）
!重要文件.txt
```

## 常见问题

### 连接服务器失败

**错误提示**：请检查 p4 set 中 P4PORT

**解决方法**：
```bash
p4 set P4PORT=正确的服务器地址:端口
```

### 用户设置错误

**错误提示**：请检查 p4 set 中 P4USER

**解决方法**：
```bash
p4 set P4USER=正确的用户名
```

### 未检测到流客户端

**错误提示**：未在本地检测到用户 xxx 所属的流客户端

**原因**：当前主机没有属于该用户的流类型客户端

**解决方法**：
1. 使用 P4V 或命令行创建流客户端
2. 确保客户端的 Host 设置为当前主机名
3. 确保客户端关联了 Stream

### 检测到未提交文件

**错误提示**：检测到 N 个未提交的文件，请先提交或撤销修改

**原因**：当前客户端有打开（checkout）但未提交的文件

**解决方法**：
1. 使用 P4V 提交修改：`p4 submit`
2. 或撤销修改：`p4 revert //client/...`

### 检测到 P4V 运行中

**错误提示**：检测到 P4V 正在运行中

**原因**：切换工作区时 P4V 运行可能导致文件锁定或缓存不一致

**解决方法**：
1. 关闭 P4V
2. 重新点击"一键切换"
