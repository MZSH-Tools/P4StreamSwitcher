# P4StreamSwitcher

Perforce 流工作区一键切换工具，帮助用户快速在不同流分支之间切换，无需手动修改客户端配置。

## 核心功能

- **流客户端管理**：自动识别本地主机上当前用户的流客户端
- **项目/分支切换**：下拉选择目标流项目和分支，一键应用
- **自动同步**：切换后自动执行 `sync -k` 链接服务器文件
- **自动清理**：可选执行 `clean` 命令清理工作区多余文件
- **进度可视化**：实时显示操作进度和详细日志

## 使用场景

- 需要频繁在多个流分支之间切换的开发者
- 希望避免手动编辑 P4 客户端配置的用户
- 多项目并行开发，需要快速切换工作环境

## 环境要求

- Python 3.x
- P4Python（Perforce Python API）
- 已配置 P4PORT、P4USER 等环境变量

## 快速开始

```bash
python Main.py
```
