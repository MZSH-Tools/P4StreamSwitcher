# P4StreamSwitcher

> 本工具为个人开发使用，仅支持深度为 2 的 P4 Stream 结构（如 `//depot/project/branch`）。如有其他需求请自行修改源码。

Perforce 流工作区一键切换工具，帮助用户快速在不同流分支之间切换，无需手动修改客户端配置。

## 核心功能

- **流客户端管理**：自动识别本地主机上当前用户的流客户端
- **项目/分支切换**：下拉选择目标流项目和分支，一键切换
- **工作区目录缓存**：自动记住每个流对应的工作区目录，支持浏览按钮手动选择，路径来源可视化（缓存/默认/手动）
- **智能同步**：基于 `.p4ignore` 智能保护缓存文件（Saved/、Intermediate/、DerivedDataCache/ 等）
- **精准更新**：使用 `diff -se/-sd` 精准检测差异文件，只下载需要的文件
- **离线目录支持**：标记离线目录后使用 `reconcile` 保留本地修改，差异放入默认 changelist
- **P4V 快捷启动**：一键打开 P4V 并自动切换到当前客户端
- **安全检查**：切换前检查未提交修改和 P4V 运行状态，防止冲突
- **进度可视化**：实时显示操作进度和详细日志

## 使用场景

本工具专为以下场景设计：

**免费版 Perforce 工作区数量受限**：免费版 Perforce 对工作区数量有限制，无法为每个项目/分支创建独立工作区。本工具通过复用单个流工作区，实现多项目、多分支的快速切换。

**深度为 2 的 Stream 结构**：适用于 `//depot/project/branch` 形式的流结构（如 `//UE5/ProjectA/main`、`//UE5/ProjectA/dev`），支持在同一 depot 下的不同项目和分支间切换。

**一键切换 + 自动同步**：选择目标项目和分支后，工具自动完成客户端配置修改、工作区目录切换、文件同步校准等操作，无需手动干预。

其他适用场景：
- 多项目并行开发，需要快速切换工作环境
- UE 项目开发者（自动保护着色器缓存，避免重复编译）

## 环境要求

- Python 3.x
- P4Python（Perforce Python API）
- platformdirs（跨平台目录管理）
- 已配置 P4PORT、P4USER 等环境变量

## 快速开始

```bash
python Main.py
```
