# P4StreamSwitcher

> 本工具为个人开发使用，仅支持深度为 2 的 P4 Stream 结构（如 `//depot/project/branch`）。如有其他需求请自行修改源码。

Perforce 流工作区一键切换工具，帮助用户快速在不同流分支之间切换，无需手动修改客户端配置。

## 核心功能

- **多工作区管理**：通过工作区标识自动创建和管理多个工作区（如 `标识_项目_分支`）
- **标识冲突检测**：自动检测标识是否被其他主机使用，保存时可批量重命名旧工作区
- **项目/分支切换**：下拉选择目标流项目和分支，一键切换并打开 P4V
- **工作区目录缓存**：自动记住每个流对应的工作区目录，支持手动选择，路径来源可视化
- **工作区名称预览**：实时显示工作区名称，黑色表示已存在，灰色表示待创建
- **智能同步**：基于 `.p4ignore` 智能保护缓存文件（Saved/、Intermediate/、DerivedDataCache/ 等）
- **精准更新**：使用 `diff -se/-sd` 精准检测差异文件，只下载需要的文件
- **离线目录支持**：标记离线目录后使用 `reconcile` 保留本地修改，差异放入默认 changelist
- **工作区池管理**：达到上限时自动删除最旧工作区，基于本地时间戳判断
- **安全检查**：复用工作区时检查未提交修改，切换前检查 P4V 运行状态
- **状态栏显示**：底部显示服务器/用户和使用工作区数量

## 使用场景

本工具专为以下场景设计：

**免费版 Perforce 工作区数量受限**：免费版 Perforce 对工作区数量有限制，无法为每个项目/分支创建独立工作区。本工具通过工作区标识自动管理多个工作区，在限制内实现多项目、多分支的快速切换。工具只管理符合 `标识_项目_分支` 命名格式的工作区，用户自建的其他工作区不纳入管理。

**深度为 2 的 Stream 结构**：适用于 `//depot/project/branch` 形式的流结构（如 `//UE5/ProjectA/main`、`//UE5/ProjectA/dev`），支持在同一 depot 下的不同项目和分支间切换。

**一键切换 + 自动同步**：选择目标项目和分支后，工具自动完成客户端配置修改、工作区目录切换、文件同步校准等操作，完成后自动打开 P4V。

其他适用场景：
- 多项目并行开发，需要快速切换工作环境
- UE 项目开发者（自动保护着色器缓存，避免重复编译）

## 环境要求

- Python 3.x
- P4Python（Perforce Python API）
- platformdirs（跨平台目录管理）
- 已配置 P4PORT、P4USER 等环境变量

## 快速开始

```bash
python Main.py
```
