# P4StreamSwitcher

> 本工具为个人开发使用，仅支持深度为 2 的 P4 Stream 结构（如 `//depot/project/branch`）。如有其他需求请自行修改源码。

Perforce 流工作区一键切换工具，帮助用户快速在不同流分支之间切换，无需手动修改客户端配置。

## 核心功能

- **流客户端管理**：自动识别本地主机上当前用户的流客户端
- **项目/分支切换**：下拉选择目标流项目和分支，一键切换
- **工作区目录缓存**：自动记住每个流对应的工作区目录，支持浏览按钮手动选择，路径来源可视化（缓存/默认/手动）
- **智能同步**：基于 `.p4ignore` 智能保护缓存文件（Saved/、Intermediate/、DerivedDataCache/ 等）
- **精准更新**：使用 `diff -se/-sd` 精准检测差异文件，只下载需要的文件
- **安全检查**：切换前检查未提交修改和 P4V 运行状态，防止冲突
- **进度可视化**：实时显示操作进度和详细日志

## 使用场景

- 需要频繁在多个流分支之间切换的开发者
- 希望避免手动编辑 P4 客户端配置的用户
- 多项目并行开发，需要快速切换工作环境
- UE 项目开发者（自动保护着色器缓存，避免重复编译）

## 环境要求

- Python 3.x
- P4Python（Perforce Python API）
- platformdirs（跨平台目录管理）
- 已配置 P4PORT、P4USER 等环境变量

## 快速开始

```bash
python Main.py
```
