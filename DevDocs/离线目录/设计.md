# 离线目录

## 需求

- [x] 支持将本地目录标记为"离线目录"
- [x] 离线目录切换时以本地文件为准
- [x] 使用 `reconcile` 识别本地与 depot 的差异
- [x] 差异放入默认 changelist，用户在 P4V 中处理

## 设计方案

### 使用场景

适用于已有本地文件（如从其他来源获取的项目），需要与 Perforce 关联但保留本地修改的情况。

### 切换流程对比

| 步骤 | 普通目录 | 离线目录 |
|------|---------|---------|
| 1 | sync -k | sync -k |
| 2 | 删除多余文件 | - |
| 3 | diff -se/-sd | - |
| 4 | sync -f --parallel | reconcile --parallel |
| 结果 | 本地与 depot 一致 | 差异放入默认 changelist |

### reconcile 命令

```bash
p4 reconcile -a -e -d --parallel=threads=8 //client/...
```

参数说明：
- `-a`：检测本地新增文件
- `-e`：检测本地编辑文件
- `-d`：检测本地删除文件
- `--parallel=threads=8`：8 线程并行

### 缓存结构

```json
{
  "//depot/project/branch": {
    "workspace": "D:/workspace",
    "offline": true
  }
}
```

## 边界问题与解决方案

| 问题 | 解决方案 |
|------|----------|
| 目录为空 | 正常执行，reconcile 无结果 |
| 大量差异文件 | 8 线程并行处理 |
| 用户取消 | 在 P4V 中 revert 即可 |
