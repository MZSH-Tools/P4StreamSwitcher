# P4StreamSwitcher - 开发文档

## 项目大纲

P4StreamSwitcher 是一个基于 tkinter 的 Perforce 流工作区一键切换工具，帮助用户快速在不同流分支之间切换。

### 架构

```
Main.py                     # 程序入口
Source/
├── Data/
│   ├── P4Core.py          # P4 API 封装（连接、同步、reconcile 等）
│   └── WorkspaceCache.py  # 缓存管理（工作区目录、全局配置、时间戳）
├── Logic/
│   └── Callbacks.py       # 业务逻辑（事件处理、切换流程）
└── UI/
    └── UIComponents.py    # UI 组件（窗口、控件、日志）
```

### 核心流程

```
选择项目/分支 → 检查工作区是否存在？
             → [存在] → 直接打开 P4V（极速）
             → [不存在] → 检查上限
                       → [未达上限] → 创建 → 同步/reconcile → 打开 P4V
                       → [已达上限] → 检测最旧工作区（P4V运行+未提交）
                                   → [有问题] → 报错，要求手动处理
                                   → [无问题] → 删除 → 创建 → 同步 → 打开 P4V
```
