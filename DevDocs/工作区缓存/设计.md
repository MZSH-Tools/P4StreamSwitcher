# 工作区缓存

## 需求

- [x] 记住每个流对应的工作区目录，避免重复输入
- [x] 允许用户手动浏览选择目录
- [x] 切换前检测 P4V 是否运行，避免冲突
- [x] 目录不存在时提示并可自动创建
- [x] 区分路径来源：缓存、默认、手动选择

## 设计方案

### 缓存结构

使用 platformdirs 获取跨平台缓存目录：
- Windows: `%LOCALAPPDATA%\mengzhishanghun\P4StreamSwitcher`
- Mac: `~/Library/Caches/mengzhishanghun/P4StreamSwitcher`

```
缓存目录/
└── config.json    # 统一配置文件（全局配置 + 流缓存）
```

### 配置文件内容

```json
{
  "workspace_tag": "zhangsan",
  "max_workspace_cnt": 5,
  "create_p4config": true,
  "auto_rmdir": true,
  "workspace_timestamps": {
    "zhangsan_UE5_main": 1705123456,
    "zhangsan_UE5_dev": 1705123400
  },
  "stream_cache": {
    "//UE5/ProjectA/main": {
      "workspace": "D:/Workspace/ProjectA_main",
      "offline": false,
      "need_sync": false
    },
    "//UE5/ProjectA/dev": {
      "workspace": "D:/Workspace/ProjectA_dev",
      "offline": true,
      "need_sync": true
    }
  }
}
```

| 字段 | 说明 |
|------|------|
| workspace_tag | 工作区标识前缀 |
| max_workspace_cnt | 最大工作区数量 |
| create_p4config | 是否创建 .p4config 文件 |
| auto_rmdir | 是否自动删除空文件夹（修改时同步应用到所有工作区） |
| workspace_timestamps | 工作区最后使用时间戳（用于淘汰最旧工作区） |
| stream_cache | 流路径到工作区目录的映射 |

stream_cache 条目字段：

| 字段 | 说明 |
|------|------|
| workspace | 工作区目录路径 |
| offline | 是否为离线目录（创建时以本地文件为准） |
| need_sync | 是否需要同步（创建时设为 true，同步成功后设为 false） |

### 路径获取优先级

切换流时，按以下优先级获取工作区目录：

1. **已存在的工作区** → 从 P4 服务器获取 Root 目录，并更新缓存
2. **本地缓存** → 从 stream_cache 获取之前保存的路径
3. **默认路径** → 自动生成 `{workspace_root}/{project}` 格式的路径

### 路径来源标识

| 来源 | 颜色 | 说明 |
|------|------|------|
| 工作区/缓存 | 正常 | 从已存在工作区或缓存获取 |
| 默认 | 灰色 | 自动生成的默认路径，需确认 |
| 手动 | 正常 | 用户手动选择 |

## 边界问题与解决方案

| 问题 | 解决方案 |
|------|----------|
| 缓存文件损坏 | 捕获异常，重置为空缓存 |
| 旧格式缓存 | 自动迁移到新格式 |
| 目录不存在 | 弹窗询问是否创建 |
| P4V 运行中 | 拒绝切换，提示关闭 |
| 同步中断/失败 | 保留 need_sync=true，下次切换时自动重试 |
| 旧缓存无 need_sync 字段 | GetNeedSync 返回 false，不影响已有工作区 |
| 工作区存在但无缓存 | 优先从 P4 获取 Root 目录并更新缓存 |
