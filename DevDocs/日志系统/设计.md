## 设计方案

### 日志级别

| 级别 | 颜色 | 用途 |
|------|------|------|
| INFO | 黑色 | 普通信息 |
| WARNING | 橙色 | 警告信息（如同步重试） |
| ERROR | 红色 | 错误信息 |

### 日志格式

```
[HH:MM:SS] 日志内容
```

示例：
```
[14:30:25] 执行 sync -k 更新 have list...
[14:30:26] have list 更新完成。
[14:30:27] 检测到上次同步未完成，重新执行同步...  (橙色)
[14:30:28] 同步操作中发生错误：连接超时  (红色)
```

### API 设计

```python
class LogLevel:
    INFO = "info"
    WARNING = "warning"
    ERROR = "error"

# 基础方法
LogMessage(Msg, Level=LogLevel.INFO, ShowTime=True)

# 便捷方法
LogInfo(Msg)      # 等同于 LogMessage(Msg, LogLevel.INFO)
LogWarning(Msg)   # 等同于 LogMessage(Msg, LogLevel.WARNING)
LogError(Msg)     # 等同于 LogMessage(Msg, LogLevel.ERROR)
```

### P4Exception 错误处理

```python
# 修复前：E.errors 可能为空列表
self.ui.LogMessage("错误：" + "\n".join(E.errors))  # 可能只显示 "错误："

# 修复后：使用 str(E) 作为备选
ErrMsgs = E.errors if E.errors else [str(E)]
self.ui.LogError("错误：" + "\n".join(ErrMsgs))
```
